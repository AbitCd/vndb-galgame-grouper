A Visual Novel (Galgame) folder management tool that automates sorting and organizing visual novel folders based on VNDB data. Features include grouping by developers, voice actors, and other tags, as well as renaming folders to standardized visual novel titles. Built on VNDB API, it offers multiple usage options and customizable settings.

## ✨ Features

- 🎮 VNDB Database Integration
  - Fast fuzzy matching for titles (average 3s per item)
  - Pattern matching for various naming formats
  - Adjustable matching accuracy settings

- 📂 Intelligent Organization
  - Separates VN and non-VN content automatically 
  - Groups by companies, staff roles, and more
  - Flexible tag-based sorting options

- 🔄 Smart Renaming System
  - Standardized naming conventions
  - Supports original/localized titles
  - Retains critical metadata

- 💡 Versatile Usage Options
  - User-friendly GUI interface
  - Command line functionality
  - Custom configuration support

## 💻 System Requirements

## ⚡ Performance Tips

- Initial run downloads and builds search index (several minutes)
- Enable caching for faster processing:
  ```bash
  python main.py --folder /path/to/games --api-cache --group-cache
  ```
- For large collections:
  - Store cache on SSD
  - Fine-tune matching sensitivity
  - Use batch processing mode

## 🚀 Quick Start

1. Install dependencies
```bash
pip install -r requirements.txt
```

2. Run the tool
```bash
# GUI mode
python main.py

# CLI mode
python main.py --cli
```

3. Basic usage examples
```bash
# Process specific folder
python main.py --folder /path/to/games

# Enable fuzzy matching
python main.py --folder /path/to/games --enable-fuzzy-match

# Full feature example
python main.py --folder /path/to/games --do-vn-group --tag-field developers --normalize
```

## ❓ FAQ

1. **How to improve matching accuracy?**
   - Adjust fuzzy_match_threshold (default 0.4)
   - Apply regex_filter for name preprocessing
   - Use debug_mode to analyze matching details

2. **Why is processing slow?**
   - Verify cache is enabled
   - Test network connectivity
   - Try batch processing option

3. **How are non-English characters handled?**
   - Built-in support for Japanese/Chinese
   - Use normalize_name function
   - Custom character filtering available

4. **Access denied errors?**
   - Check folder permissions
   - Run as administrator
   - Verify file system access rights
